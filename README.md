# Auto Retry

## 介紹
Auto Retry 是一個簡單的 Google 擴充功能，可以將指定頁面自動重新刷新。它能幫助使用者執行項目或網頁的更新任務。

## 安裝指南
1. 前往 Google Chrome 的擴充功能管理頁面。
2. 新增未載入封裝的擴充功能，安裝 Auto Retry。

## 使用方法
1. 可以設定清楚的參數，通過修改項目來設定刷新的項目速度。
